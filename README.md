# Sa'ida Alrowwad Portfolio

## Project Overview
A responsive personal portfolio website built from scratch using HTML, CSS, and JavaScript without frameworks, templates, or UI libraries.

## Features
- **Header/Navbar:** Navigation between website sections.
- **About Me:** Personal introduction with a photo.
- **Skills Grid:** Displays skills using CSS Grid.
- **Project Showcase:** Presents Projects 00–03.
- **Hobbies:** Highlights personal interests.
- **Contact Form:** Uses HTML form attributes such as `action` and `method`.
- **Theme Switcher:** Changes the background color dynamically using JavaScript.
- **Responsive Design:** Uses Flexbox and CSS media queries.
- **Footer:** Displays additional information and links.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## JavaScript Event Lifecycle
1. **User Action:** The user clicks the theme switcher.
2. **Event Firing:** The browser triggers the `click` event.
3. **JavaScript Callback:** The event handler executes.
4. **DOM/CSS Mutation:** JavaScript updates the styles or CSS class to change the theme.

## Getting Started
1. Download or clone the project.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.

## Project Goals
- Practice HTML forms and semantic structure.
- Learn CSS Grid, Flexbox, and responsive design.
- Understand JavaScript events and DOM manipulation.
- Build an authentic personal portfolio.
